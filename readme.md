This is the first programming assignment to get you acquainted with Gradescope and doing demos with the TAs.

The task is to complete the greeter.py module, that defines a class Greeter, which stores the name and place provided by the input. There is a method called "greeting" that you should add a print statement to print:

Hello, Fred, welcome to Fiji

Where "Fred" and "Fiji" are the name and place provided. Note the punctuation. It has to be exactly like this to work in Gradescope. Sorry if that sounds like a strict requirement, but there are all kinds real-world situations where exact formatting is required.

When you run the main.py, you should provide the name as the first argument, and the place as the second argument. If the name and/or place have multiple words and spaces, you need to put them in quotes (but this part is already done for you).

python main.py 'Jane Doe' 'Corvallis, Oregon'

output:

Hello, Jane Doe, welcome to Corvallis, Oregon
